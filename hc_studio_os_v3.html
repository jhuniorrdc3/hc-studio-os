FIREBASE — BASE DE DATOS COMPARTIDA
Tú y Daniela ven los mismos datos desde cualquier dispositivo
Sin configurar
Setup en 4 pasos (5 minutos):
1. Ve a console.firebase.google.com → Crear proyecto (nombre: hc-studio-os)
2. Menú izquierdo → Realtime Database → Crear base de datos → Modo de prueba
3. En la pestaña Reglas, confirma que diga ".read": true, ".write": true
4. Copia la URL y pégala aquí abajo → "Probar conexión"
✅ Sin Apps Script. Sin login de Google. Funciona desde cualquier celular aunque esté logueado con otra cuenta.
